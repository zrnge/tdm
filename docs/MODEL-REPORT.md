### Verdict

The skeleton *is* Mixamo-compatible in naming — the `mixamorig7:` prefix is a

retargeting is still impossible here**, because Mixamo's locomotion clips drive
`Hips`, `Spine`, `LeftUpLeg`, `RightUpLeg`, `LeftFoot`, etc. — and this skeleton
has none of those bones. There is nothing to drive. This is the case your
instructions told me to stop on rather than guess at.

It is a high-quality, fully rigged AK74U with a working trigger, bolt, magazine,
and safety, plus fire and reload animations. It is a strong candidate for the
**first-person viewmodel** if you ever add a first-person camera mode, and its
`SHOOT` / `RELOAD1` / `RELOAD2` clips are usable for weapon animation ideas.
It is **not** usable for the 8 third-person characters.

### Bugs found and fixed during this pass

1. **SkinnedMesh invisible.** The character rendered as nothing because
   `frustumCulled` defaults to `true` and a skinned mesh's bind-pose bounding
   volume does not contain its posed geometry. Fixed by setting
   `frustumCulled = false` on skinned meshes — this must also be done in the
   game's character factory.
2. **Wrong normalisation scale.** `Promise.all` resolves in *network-completion*
   order, not request order, so the 4 MB warehouse finished first and the
   character was normalised using the warehouse's 5.024 m height (scale 0.3583
   instead of 1.0480). Fixed by returning `{ root, stats }` as a pair and using
   each model's own stats.
3. **`THREE.Clock` deprecation warning.** Three.js 0.186 deprecates `Clock` in
   favour of `Timer`. Replaced with a `performance.now()` delta, which also
   avoids the console warning.
4. **404 on `/favicon.ico`.** Added an inline SVG data-URI favicon.

### Rifle decision (supersedes the earlier bake plan)

The rifle was originally to be baked out of the supplied viewmodel at runtime.
That was **abandoned deliberately**:

1. The rifle is **49,666 triangles**. Eight characters would carry ~400,000
   triangles of gun — more than the entire level, and 8× the per-character
   budget.
2. It is skinned across joints hanging off a free-floating `Bone_043`, so the
   weapon only reaches the hands at particular frames of particular clips. A
   rigid attachment has to be recovered by baking a frame, which is fragile.

Instead, a **procedural placeholder rifle** (120 triangles, correct 0.73 m
AK-74U proportions, grip at the origin, barrel down -Z) is attached to
`RightHand`. Drop a real low-poly rifle at `public/models/rifle.glb` and the
loader uses it automatically. The grip is tuned visually with the **F4** tool,
which prints a paste-ready `RIFLE.grip` block.

The supplied file is retained for its real purpose: the **first-person
aim-down-sights viewmodel**, where exactly one instance exists and its 69k
triangles are paid once.
